# bhasa

## Compile

```sh
# Build Docker image (first time only)
./build.sh

# Compile PDFs (pdflatex - IPA only)
./compile_pdflatex.sh

# Compile PDFs (xelatex - with native scripts)
./compile_xelatex.sh

# Clean auxiliary files
./clean-latex-artifacts.sh
```
